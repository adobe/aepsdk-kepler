# Development

## Requirements

- VSCode
- Kepler SDK
- Node
- Yarn

## Install dependencies

Run `yarn install` in the root directory to install the npm dependencies.

## Build

Run `yarn build_all` in the root directory to build all npm packages.

## Tests

- Unit Test

Run `yarn unit_test` in the root directory to trigger unit tests across all packages.

- Integration Test

Run `yarn integration_test` in the root directory to trigger integration tests.

## Archive

Run `yarn archive_all` in the root directory to archive all packages.
